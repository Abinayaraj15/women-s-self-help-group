Developer & Identity Architecture

OAuth 2.0 Integration & Secure Single Sign-On (SSO) Guide

Technical documentation and architecture specification for integrating rural women Self Help Group federations, government digital identity systems (MeriPehchan, DigiLocker), and partner payment gateways into HerVana.

📅 Effective: November 2026 • 🏛️ NRLM Fair Trade Certified • ✅ Legally Audited for Women SHGs
🔑

1. Identity & SSO Architecture Overview

HerVana utilizes OAuth 2.0 and OpenID Connect (OIDC) with PKCE (Proof Key for Code Exchange) to provide seamless, bank-grade authentication across web, mobile, and rural village kiosk environments.

  • Supported Identity Providers (IdPs): MeriPehchan (Govt of India National SSO), DigiLocker Citizen Verification, Google Identity Services, and Mobile OTP (Aadhaar-linked).
  • Authorization Grant Type: Standard Authorization Code Flow with PKCE (RFC 7636) for maximum security without requiring client secrets in public apps.
  • JWT Token Lifecycle: Access tokens (15-minute expiry) signed with RS256, paired with secure rotating refresh tokens (30-day rolling).
⚙️

2. API Scopes & Role-Based Permissions

Our API enforces strict least-privilege role boundaries ensuring SHG cooperative records, artisan personal data, and patron payments remain compartmentalized.

  • openid profile email: Standard OpenID Connect claims for authenticating buyer patrons and verifying artisan phone/email.
  • shg:read shg:catalog: Grants access to retrieve group inventory, manage product variants, and update handcrafted stock levels.
  • orders:dispatch: Allows village logistics partners to mark postal consignments as dispatched and generate India Post manifests.
  • financials:payout_read: Restricted strictly to authenticated SHG Leader and Treasurer credentials for reviewing PFMS settlement history.
💻

3. Implementation Code Example (cURL & JavaScript)

Federation developers and rural cooperative ERP integrators can authenticate in 3 simple steps:

  • Step 1 - Authorization Request: GET https://auth.hervana.org/oauth/authorize?response_type=code&client_id=shg_portal&redirect_uri=https://app.hervana.org/callback&scope=openid+shg:catalog&code_challenge=xyz&code_challenge_method=S256
  • Step 2 - Token Exchange: POST https://auth.hervana.org/oauth/token with grant_type=authorization_code, code, and code_verifier.
  • Step 3 - Authenticated API Call: GET https://api.hervana.org/v1/shg/orders with header Authorization: Bearer .
